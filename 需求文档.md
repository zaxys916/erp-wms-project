## 1. 项目概述

### 1.1 项目背景

本系统是一套面向中小型企业的 **ERP（企业资源计划）+ WMS（仓储管理系统）** 一体化解决方案，覆盖采购、销售、库存、仓储等核心业务环节，帮助企业实现进销存数字化管理。

### 1.2 项目目标

- 提供统一的后端 RESTful API，支撑 Web 端（Vue + TypeScript）业务操作。
- 实现库存实时管理、出入库单据流程、库存盘点与差异跟踪。
- 保证系统高可用、可监控、可扩展，支持容器化部署。

### 1.3 目标用户

| 角色        | 说明                         |
| ----------- | ---------------------------- |
| 系统管理员  | 用户管理、权限分配、系统配置 |
| 仓库管理员  | 出入库操作、盘点、库位管理   |
| 采购/销售员 | 订单创建与跟踪（规划中）     |
| 普通用户    | 查询浏览库存、订单           |

## 3. 系统架构

```
┌─────────────────────────────────────────────────────┐
│            前端 Vue3 + TS (Vite:5173)                │
│  登录 → 路由守卫 → 页面(Element Plus) → api 封装层     │
└───────────────────────┬─────────────────────────────┘
                        │ HTTP/JSON + JWT（Bearer）
┌───────────────────────▼─────────────────────────────┐
│        FastAPI (Uvicorn:8000) 统一入口 src/main.py   │
│ routers → schemas → services → models                │
└───┬──────────────────────┬──────────────────────────┘
    │                      │
┌───▼────────┐     ┌───────▼───────┐      ┌────────────┐
│   MySQL    │     │    Redis      │      │  Celery    │
│  wms_db    │     │ (规划:缓存/限流)│      │ (规划)      │
└────────────┘     └───────────────┘      └────────────┘
```

后端分层：

- `src/routers/`：路由（仓库、库位、产品、库存、单据、盘点、用户、认证、权限）
- `src/schemas/`：Pydantic 请求/响应模型
- `src/services/stock_service.py`：库存变动核心（统一增减 + 写流水 + 行锁）
- `src/models.py`：SQLAlchemy ORM 模型（单一入口，供 Alembic autogenerate）
- `src/security.py` / `src/dependencies.py`：密码哈希、JWT、RBAC 依赖
- `alembic/`：数据库版本迁移

## 4. 功能需求（状态与实现同步）

> 状态取值：✅ 已实现 · 🟡 部分/简化 · ⬜ 未开发

### 4.1 用户认证与权限（✅ 基础完整，🟡 角色分配 UI 待完善）

#### 4.1.1 功能描述

- 用户注册、登录；注册统一为 `user` 角色（防越权自建 admin）。
- 基于 JWT 的无状态认证；基于角色的访问控制（RBAC）已挂到全部业务路由。
- 管理类接口（用户管理等）仅 `admin` 可访问；业务写入对 `operator` 开放；`user` 只读。

#### 4.1.2 详细需求

| 编号    | 需求                                | 优先级 | 状态                                                |
| ------- | ----------------------------------- | ------ | --------------------------------------------------- |
| AUTH-01 | 用户注册（用户名唯一、邮箱唯一）    | 高     | ✅                                                  |
| AUTH-02 | 用户登录并签发 JWT（30 分钟过期）   | 高     | ✅                                                  |
| AUTH-03 | 密码使用 bcrypt 哈希存储            | 高     | ✅                                                  |
| AUTH-04 | 获取当前用户、校验是否激活          | 高     | ✅                                                  |
| AUTH-05 | 角色管理（admin / operator / user） | 中     | 🟡 创建时可指定 role；无可视化改角色入口            |
| AUTH-06 | 权限中间件，按角色限制接口访问      | 中     | ✅ `require_permission` 已挂到全部业务路由          |
| AUTH-07 | 用户禁用/启用、重置密码             | 中     | ✅                                                  |
| AUTH-08 | CORS 跨域配置                       | 高     | ✅ 白名单可配（`CORS_ORIGINS`），默认含本地开发地址 |

#### 4.1.3 接口清单（实际路径）

| 方法 | 路径                             | 说明                                   |
| ---- | -------------------------------- | -------------------------------------- |
| POST | /api/auth/token                  | 登录（OAuth2 表单），返回 access_token |
| POST | /api/auth/register               | 用户注册（角色强制 user）              |
| GET  | /api/auth/users/me               | 当前用户信息                           |
| POST | /api/auth/logout                 | 登出（前端清 token）                   |
| GET  | /api/permission/roles            | 角色-权限矩阵                          |
| GET  | /api/permission/me/permissions   | 当前用户权限列表                       |
| GET  | /api/permission/users/{id}/roles | 指定用户角色（admin）                  |
